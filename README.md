# heyclicky clone

Pixel-faithful recreation of [heyclicky.com](https://www.heyclicky.com/) built as a static Vite app.

The homepage, changelog, and privacy pages reuse the live site’s layout CSS, media, copy, and interaction model: macOS menubar, draggable desktop windows, feature rows, manifesto, social proof, pricing toggle, FAQ accordion, and footer easter eggs.

## Run

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

```bash
npm run build
npm run preview
```
